# Tag vocabulary

The Tags of the Game library, spelled exactly as here: the first spelling of a key sticks for the whole library (`saveTags`), and the key is the label lower-cased. A Tag has at most 20 characters, a game at most 8 Tags. Labels mix German and English on purpose, the way the group talks.

When more than 8 fit a game, keep them in this order: Price, Genre, Launcher, Setup, Play style.

## Price

| Tag | Meaning |
|---|---|
| Free-to-play | No Price: nobody pays to play it the way we play it, which includes a free demo and a local copy the Host shares. Set on 2026-11-10 for every game without a Price (#423 makes it automatic). A paid game gets its Price instead. |

## Genre (one or two per game)

| Tag | Meaning |
|---|---|
| Shooter | Aiming and shooting is the core, first or third person, or 2D. |
| Battle Royale | Many players or teams in one match, the last one standing wins; party royales (Fall Guys) count. |
| MOBA | Lanes, heroes, objectives; one match is long. |
| Fighting | Fighters or platform fighters: knock the others out with moves and timing. |
| Arena | Top-down or arena brawlers that are neither Shooter nor Fighting: spells, boomerangs, builds. |
| Platformer | Jump-and-run, climbing, or building a course to run. |
| Sport | A real sport played as a game: football with cars, hockey, basketball, disc. |
| Racing | First to the finish or best time. |
| Golf | Golf in any form. |
| Party | Minigame collections and board-game-style party games. |
| Physics | Wobbly physics-driven controls are the point and the fun. |
| Strategie | Planning beats reflexes: real-time strategy, artillery, board strategy. |
| Quiz | Guessing and knowledge. |
| Puzzle | Solving puzzles, alone or together, or a puzzle game played as a duel. |

## Play style

| Tag | Meaning |
|---|---|
| Skill | The better player wins reliably; practice shows. |
| Casual | Easy to pick up, fun first; newcomers stand a chance. |
| Gamba | High RNG: luck decides a lot. |
| Social | Talking, bluffing or reading each other is the core (was „Kommunikation“ and „Bluff“). |
| Schnell | One round takes a few minutes, so a Session holds many. |
| Lang | One match takes 30 minutes or more. |
| Rundenbasiert | Players take turns. |
| Parallel | The teams play side by side and compare scores, never touching each other: no shared lobby, each team streams on its own. |
| Unlocks | Progress or purchases change what a Player can do: loadouts, characters, level-ups, card packs. |

## Setup on game night

| Tag | Meaning |
|---|---|
| No-Spec | The game has no spectator slot, so a Player hosts the lobby. |
| Mod nötig | It needs a mod for the way we play it (more players, our maps). |
| Eigener Server | The Host sets up a server or its config files before the night. |
| Nur lokal | No online multiplayer: local only. |
| Remote Play | Works over Steam Remote Play Together, so a local game runs online through the Host. |
| Demo | We play a demo, a playtest or a beta, not the full game. |

## Launcher

The client and account the Players need to play it. A game on Steam that also needs another launcher gets both. The labels are the launchers' names. A launcher missing here is a fact rather than a choice: add it in a run without asking.

| Tag | Meaning |
|---|---|
| Steam | Played through Steam. |
| Epic | Epic Games Launcher. |
| Riot | Riot Client and a Riot account. |
| Ubisoft | Ubisoft Connect and a Ubisoft account. |
| Roblox | Played inside Roblox. |
| Browser | Runs in the browser: nothing to install, a good backup game. |
