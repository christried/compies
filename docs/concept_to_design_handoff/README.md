# COMPIES – Handoff to Claude Design

## Files

| File | Purpose |
|---|---|
| `00-product-brief.md` | Full functional scope. **Attach to every phase.** |
| `phase-1-style-exploration.md` | Test style directions on their own and combined; get a recommendation |
| `phase-2-design-system.md` | Tokens and components for the chosen direction |
| `phase-3-compibert-and-motion.md` | Compibert as an animatable rig, his states, all big motion moments |
| `phase-4-screens-and-flows.md` | All screens (desktop + mobile), states, click-through flows |
| `phase-5-handoff-to-claude-code.md` | Handoff package for the rebuild with Claude Code |

## How to run it

1. Send **phase 1** with the brief attached. Review the results and pick a direction or combination.
2. In **phase 2**, enter the chosen direction at the top, then send it.
3. Send **phase 3**, **phase 4** and **phase 5** one after another, in the same Claude Design session.
4. Give the handoff package from phase 5, together with `00-product-brief.md`, to Claude Code.

## Scope labels

- **[1.0]**: first release
- **[1.0 – last ticket]**: battle replay; dropped if it isn't feasible purely with GSAP
- **[Post-1.0]**: designed now, built later (crews, tournament bracket, league, self-reported results, stands features, English)
- **[Discarded]**: do not design
