Toolbar · anatomy · 390 · 320 · keyboard

Six buttons, one row

Each button is a 44 × 44 hit area with a 36 px visual square (radius 8). Four groups: inline (Fett, Kursiv) · block (Überschrift) · lists (Liste, Nummerierte Liste) · Link; 2 px line-soft separators with 3 px air. Pressed = ink fill + paper icon (the SegmentedControl / IconButton toggle look). That is 8 + 6 × 44 + 3 × 8 = 296 px: one row on every phone from 390 down to 320 (field inside 282: the separators drop below 296, 272 left). Only below 272 (Galaxy Z Fold cover screen, 280 wide) the Link group wraps to a second row.

3 · read-only · four places · 1440 and 390 · light and dark

A formatted note, wherever it shows up

Heading = Lilita (the display face, one level). Bold = 800. Italic = slanted (Bricolage has no italic; the browser slants it, allowed with font-synthesis: style). Bullets = small squares, numbers tabular. Links = info-fg, 650, 2 px underline and a ↗ that never wraps away from the last letter, so they read as „leaves the app“; a link whose text is its address drops „https://“ and „www.“ and breaks anywhere, which keeps the 320 px popover from overflowing.

It scrolls inside, the frame stays

Popover: max 440 px (or the room below the trigger − 24), header and „Bearbeiten“ stay, only the text scrolls. Once scrolled, a 2 px line-soft rule appears under the header (no soft shadow: the DS keeps blur for toasts and tooltips). Sheet: max 76 %, same rule. Finished: the Event note is frozen

After „Event beenden“ the Event note is history: no toolbar, no pencil, dashed border (the DS read-only look), the disc turns paper-2, and a lock chip „Event beendet“ says why. The text stays fully readable (ink, not ink-3). The game's own note lives in the library, so it stays editable here too.
