App Event-Seite

Die Event-Seite trägt jetzt Spielbrett, Aktivität und den Start einer Session. Neu ist nur die Komposition: Reihenfolge und Gewicht der vorhandenen Bausteine je Zustand. Keine neuen Tokens. Übergabe: design_handoff_compies/11-event-seite.md

Kompositionsregeln

  1. Oben steht, was gerade zu tun ist. Ohne Termin: die Umfrage. Ab dem Termin: das Spielbrett. Zwischen zwei Sessions: die Sessions-Karte. Ein nicht eingerichtetes Event: der Hinweis.
  2. Sessions und „So wird gespielt“ sind Nachschlag-Karten. Sonst immer unten nebeneinander (mobil gestapelt). Während eine Session läuft, bleiben sie unten; der Kopf sagt „Session 1 von 2 läuft seit 20:34“.
  3. Eine zweite Umfrage drängelt nicht. Hat eine Session schon einen Termin und eine andere noch nicht, steht die Umfrage unter dem Brett, „Wer kann wann?“ ist zugeklappt, und der Kopf verlinkt dahin.
  4. Aktivität ist immer einen Blick entfernt. Desktop: SidePanel rechts mit einem Tab „Aktivität“, gebaut als Tabs-Pattern, damit Chat, Tabelle und Leute später nur Tabs dazubekommen. Mobil: zweiter Tab unten, gleiche Logik.
  5. Host-Steuerung ist überall gleich. Höchstens drei Aktionen plus „Mehr“, genau eine primär, egal ob der Host im Team, auf der Bench oder auf der Tribüne sitzt. Desktop: Dock unten mittig über der Bühne, nie über dem SidePanel. Mobil: Krone rechts unten über der Tab-Leiste.
