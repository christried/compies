Only the confused peak touches the edge, by 0.6 units (0.1 px at 30 px). The cheer jump lifts the whole head out of the crop and clips the crest as well; that is unchanged and the hat goes with it.
When it shows
  • Event running: my Party's rank in the Standings is 1 (ties count, so several Parties can wear it).
  • Event finished: my Party is among the Winners. Spectators and Players without a Party: never.
  • Header head only. Other Compibert instances (ceremony, moments) stay as they are.
  • Flag flips false → true while the page is open (result.saved / result.corrected): play the pop. Mount, hydration, route change, reconnect: set without motion. Flag flips true → false: remove in the same frame.
