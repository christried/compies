1 · The layer’s place

  • Event page only. Every other page keeps the dot grid (Hell) and the stage fog gradients (Dunkel) and nothing else.
  • One div.stage-smoke, first child of the stage column, a sibling of the stage scroller. position:absolute; inset:0; overflow:hidden; pointer-events:none; contain:strict; aria-hidden="true".
  • Layer: --cp-z-decor (1). Stage content stays on --cp-z-content (2); header, dock, sheets, clip, veto, toasts above as before.
  • Bounds: desktop ≥ 980: stage column only (viewport − --cp-panel-w) × (viewport − --cp-header-h). Never under the SidePanel or the header. Mobile: full width, between header (56) and TabBar.
  • Anchored to the visible stage, not to the content: it does not scroll. Its top edge is the stage’s top edge, right under the header.
  • Ground order: paper → dot grid (Hell) or stage fog --cp-tex-image (Dunkel) → smoke → cards. The dots show through the smoke; it tints them, never covers them.
  • Cards are opaque --cp-surface, so smoke is never behind card text. The only text on the ground is the Head (kicker, h1) and inline notes; in {{ recLetter }} they stand in the smoke, so section 5 checks them.

2 · Shapes and tokens

Ellipses, border-radius:50%, filled with radial-gradient(closest-side, var(--c), transparent). The soft edge is the blur: no filter: blur(), which is the expensive part on a phone. Position and size in % of the layer.

#1440: x y w h390: x y w hHellDunkel {{ s.id }}{{ s.d }}{{ s.m }}{{ s.h }}{{ s.k }}
  • Group opacity (peak): Hell {{ peakL }}, Dunkel {{ peakD }}, set on the shapes’ wrapper. Each shape breathes 0.8 → 1 of that, which is Foundations’ „± 20 %“.
  • Hell uses the decor tokens --cp-pop, --cp-mint and --cp-primary. No cobalt: cobalt over pop drops ink-2 under 4.5.
  • Dunkel uses {{ darkTok }} on top of the fog. No yellow: the fog’s spotlight is already amber. No pop where the smoke reaches the spotlight: two pop shapes overlapping there drop ink-2 under 4.5:1 (see 5).

3 · Drift

  • Loop: Foundations’ lengths, 36 + i·8 s: {{ loopList }}. Played as two legs with alternate, so each leg is half the loop.
  • Desync: delay −i·9 s, so the shapes never peak together and the page doesn’t open on frame 0.
  • Easing: --cp-ease-io per leg: a slow turn at both ends, no visible restart.
  • Path: {{ pathText }}
  • Properties: transform (translate3d + scale) and opacity only, so it stays on the compositor. will-change only while moving.
  • About „6 s“: that is the Foundations demo, which plays one cycle at 10×. The spec row says 36–76 s, and that is what ships. The „Tempo“ tweak on this page plays the 10× preview.

4 · Moments that slow it

Foundations: „One hero at a time … smoke slows to 50 %“. Done with animation.updatePlaybackRate(): it keeps the position, so nothing jumps. The switch is instant; at these speeds a shape moves under 1 px per frame, so the step can’t be seen.

{{ m.n }}{{ m.when }}{{ m.how }}

Recommendation: 0.5× for every moment Foundations names, with one extra for the Clip: the layer also fades to 50 % (--cp-dur-slower --cp-ease-out in, --cp-dur-slow --cp-ease-in out), because colour moving next to a video competes with the video for 30 s. Decor isn’t a synced moment, so no server time is needed: it follows the local moment events.

5 · Contrast over the smoke

Worst case: text on the ground where two shapes overlap at peak opacity. Text on cards is never over smoke. Computed from the token hex values. Dunkel is checked inside the amber spotlight, because smoke that reaches the top meets it there. The red row shows why pop is left out of Dunkel.

Rule for later edits: peak group opacity stays ≤ {{ peakL }} (Hell) and ≤ {{ peakD }} (Dunkel). Don’t add Sonne or pop to Dunkel or cobalt to Hell without re-checking; those are the cases that fail.

6 · Reduced, and what it costs

  • Reduced: under prefers-reduced-motion or [data-motion="reduced"]: animation:none. Still frame = the from keyframe (home, scale 1, 0.8 × peak). The moments’ rate change has no effect; the Clip dim applies instantly.
  • Confirmed: no canvas, no video, no image file. {{ costLine }}
  • No per-frame JS, no requestAnimationFrame, no filter, no mix-blend-mode, no backdrop-filter. JS only touches it at moment start and end (one updatePlaybackRate call per shape).
  • New tokens: none. Uses colour, motion (ease-io, ease-out, ease-in, dur-slower, dur-slow), layer (z-decor) and layout tokens. The loop lengths are Foundations’ literal spec values, same as today.
