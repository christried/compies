# Link a second provider by verified email

Supersedes the linking half of ADR 0008. The same person signing in with Discord first and Twitch later must land in one User, not hit an error, so implicit linking is on: a sign-in joins the existing User with the same email when the provider reports that email as verified and the User's stored email is verified too (Better Auth's default rule). Twitch only ever sends verified emails; Discord sends a `verified` flag, and an unverified one never links. Placeholder emails never match a real one. Never set `trustedProviders` or `allowDifferentEmails`: either would let an unverified email take over another person's User. Identity and the allowlist still key on provider account IDs (ADR 0002), and the explicit „Verbinden“ in the profile (T2b) stays for accounts with different emails.
