# Separate Event link and Invite link

An Event has two URLs (named Session link before ADR 0011). The Invite link `/e/<slug>-<token>` makes a signed-in User a Member (on the Stands) and redirects to the Event link `/e/<slug>`, which only Members can open. Home cards, the .ics `URL` and bookmarks all use the Event link, so rotating the Invite link (new token, same slug) locks out newcomers without breaking existing Members. The slug is the kebab-cased name plus 4 random characters and is unique; the token is 12 base62 characters, so the router splits on the last `-`. Non-Members, invalid, rotated and deleted links all get the same generic „ungültig“ page, so nobody can probe whether an Event exists. Members of a deleted Event are the exception and see that it was deleted.
