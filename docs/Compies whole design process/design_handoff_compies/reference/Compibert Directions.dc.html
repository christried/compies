1Compibert, character direction

Wer ist Compibert?

Four directions, drawn from scratch for the Memphis system. All four already follow the same rig contract: named parts, documented pivots, swappable mouths, clipped eyelids. Whichever you pick, the GSAP state machine stays the same. Move the mouse: the eyes follow.

Tweaks: colourway, outline treatment, pivot dots.

State, all four at once
Switching blends: parts ease back toward rest over 250 ms while the next state starts. Blink, breath, tail and eye-follow keep running underneath.
